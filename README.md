# QR Code Generator

Простой веб-сайт для генерации QR-кодов.

## Возможности

- ✅ Создание QR-кода для URL
- ✅ Создание QR-кода для изображений
- ✅ Создание QR-кода для видео
- ✅ Скачивание QR-кода в формате PNG
- ✅ Превью загруженных файлов

## Как использовать

1. Откройте `index.html` в браузере
2. Выберите тип контента (URL, Изображение или Видео)
3. Введите URL или загрузите файл
4. Нажмите "Создать QR"
5. Скачайте готовый QR-код

## Технологии

- HTML5
- CSS3
- JavaScript
- QRCode.js библиотека

## Запуск

Просто откройте файл `index.html` в любом современном браузере.
Никаких дополнительных установок не требуется!
