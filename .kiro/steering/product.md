# Product Overview

## QR Code Generator

A simple web-based QR code generator that supports multiple content types.

## Core Features

- **URL QR Codes**: Generate QR codes from web links
- **Image QR Codes**: Encode images as base64 and generate QR codes
- **Video QR Codes**: Encode videos as base64 and generate QR codes
- **Download**: Export generated QR codes as PNG files
- **Preview**: Display uploaded media files before QR generation

## User Interface

- Tab-based navigation for different content types
- Real-time feedback with success/error messages
- Visual preview of uploaded media
- Clean, gradient-styled interface with responsive design

## Target Audience

Users who need quick, client-side QR code generation without server dependencies or installations.
